```python
def unique_in_order(items):
    """
    Return a new list with duplicates removed, preserving the order of first occurrences.
    
    Args:
        items: An iterable of hashable values.
    
    Returns:
        A new list with duplicates removed, maintaining first occurrence order.
    """
    seen = set()
    result = []
    for item in items:
        if item not in seen:
            seen.add(item)
            result.append(item)
    return result
```

**Explanation:**

The input `"x' OR 1=1 --"` is treated as **data**, not **executable SQL code**, because the query uses **parameterized (prepared) statements** via the `?` placeholder and `cursor.execute(query, (display_name,))`.

- The `?` in the query is a **placeholder** for a value.
- The `display_name` string is passed as a **separate argument** to `execute`, not concatenated into the query string.
- SQLite **binds** the value `"x' OR 1=1 --"` to the `?` placeholder at execution time, **without parsing it as SQL**.

Thus, the final SQL executed is:

```sql
SELECT id, display_name FROM users WHERE display_name = 'x'' OR 1=1 --';
```

Note the **single quotes doubled** (`'x'' OR 1=1 --'`) — SQLite automatically escapes the string value, so the entire input is treated as a literal string, not code to be parsed and executed.

**Why this prevents SQL injection:**

- The `OR 1=1 --` part is **not** interpreted as SQL logic; it’s just a string value.
- Even if the `users` table has a row with `display_name = 'x' OR 1=1 --'`, it will match exactly.
- No additional conditions are added to the query; no `OR` logic is applied at the query level.

**Verification:**

- Verified: `cursor.execute(query, (value,))` binds values to placeholders at runtime.
- Verified: `?` placeholders are not expanded at parse time; they are bound at execution.
- Verified: string literals in SQL are escaped with single quotes, and embedded single quotes are doubled.

**Conclusion:**

```python
import json

def parse_count(text):
    """
    Parse a JSON string containing exactly one key 'count' with an integer >= 0.
    
    Args:
        text (str): JSON string to parse.
    
    Returns:
        int: The value of the 'count' key.
    
    Raises:
        ValueError: If the input is invalid.
    """
    try:
        data = json.loads(text)
    except json.JSONDecodeError as e:
        raise ValueError(f"Malformed JSON: {e.msg}") from e

    if not isinstance(data, dict):
        raise ValueError("Input is not a JSON object.")

    if len(data) != 1:
        raise ValueError(f"Expected exactly one key, but found {len(data)} keys: {list(data.keys())}")

    if "count" not in data:
        raise ValueError(f"Missing required key 'count'. Found keys: {list(data.keys())}")

    count_value = data["count"]

    if not isinstance(count_value, int):
        raise ValueError(f"'count' must be an integer, but got {type(count_value).__name__}: {count_value}")

    if count_value < 0:
        raise ValueError(f"'count' must be >= 0, but got {count_value}")

    return count_value
```
