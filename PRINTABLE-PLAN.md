# Veronica.v4

## End-to-end workflow plan

**Objective:** Build one impressive, general-purpose AI named Veronica around a qualified uncensored open foundation, then expand it through reversible modules.

**Owner:** Raine

**Operating mode:** Local development, timed RunPod evaluation, and eventual Serverless scale-to-zero.

**Definition of done:** Veronica reliably chats, reasons, writes, codes, calls tools, uses scoped memory, and supports application modules through a stable API while retaining the selected foundation's capability.

---

## C - Capture

**Scope:** core model qualification, wrapper, persona, text/chat UI, tools, memory, modular applications, packaging, and deployment.

**First milestone:** basic text/chat through Veronica's own UI and API.

**Exclusions:** training a foundation from scratch, public billing, autonomous publishing, and media execution before core chat is proven.

**Acknowledgment:** North Star Locked.

---

## R - Research

1. Pin candidate revisions and verify licenses and provenance.
2. Validate complete model artifacts and storage.
3. Benchmark untouched capability before adaptation.
4. Compare the already-bucketed 30B-A3B candidate with the newer 27B dense challenger.

**Output:** signed model-selection record.

**Acknowledgments:** Engine Accounted For; Mind Proven.

---

## E - Establish

```text
Evidence -> Qualified foundation -> Model server -> Veronica wrapper
         -> Persona -> Tools -> Memory -> Application modules
         -> Reproducible package -> Serverless release
```

**Roles:** Core Builder, Capability Evaluator, Release Keeper, and owner approval.

**Durable statuses:** intake, validated, hold, ready, in progress, approval pending, qualified, selected, rejected, completed, blocked, failed, and superseded.

**Acknowledgment:** Trail Marked.

1. Build and test the local wrapper without a paid GPU.
2. Start a candidate on a timed RunPod GPU.
3. Connect the wrapper through an OpenAI-compatible endpoint.
4. Preserve the stable `Veronica` model alias.

**Output:** working basic chat and complete run evidence.

**Acknowledgments:** Shell Awakened; First Pulse.
