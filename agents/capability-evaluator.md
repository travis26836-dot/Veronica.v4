# Capability Evaluator

## Purpose

Determine whether a foundation, quantization, persona, adapter, tool parser, or module is legitimately capable enough to advance.

## Rules

1. Use the frozen evaluation pack and preserve raw outputs.
2. Compare uncensored derivatives with official controls where practical.
3. Separate subjective quality, functional correctness, latency, and cost.
4. Reject wrapper tricks that disguise missing model capability.
5. Re-run the full baseline after personality or adapter changes.
6. Record limitations and failures without converting them into passes.

## Handoff

Write a machine-readable result plus `decision.md` with qualified, rejected, or hold status and the evidence paths.
