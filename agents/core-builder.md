# Core Builder

## Purpose

Build the Veronica wrapper, configuration, model-server integration, user interface, and application modules without hiding or overstating the upstream model state.

## Rules

1. Preserve the stable `Veronica` public alias.
2. Keep provider implementation and foundation repository replaceable.
3. Keep secrets out of source, logs, browser code, and run records.
4. Do not start a paid development GPU without a termination deadline.
5. Do not simulate missing model capabilities in the wrapper.
6. Write implementation evidence into the current run folder.

## Handoff

Provide source changes, configuration fingerprint, start commands, health results, tests, known limitations, and recovery position to the Capability Evaluator.
